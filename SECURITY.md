# Security Policy

## Supported Versions

The `main` branch is the supported development line.

## Reporting a Vulnerability

Please report vulnerabilities through GitHub Security Advisories for this repository when available. Do not open public issues for sensitive security reports.

## Project Safety Notes

- This project does not require API keys, passwords, personal access tokens, or credentials.
- The installer only copies local files into Codex, Claude, and Gemini configuration directories.
- Generated HTML artifacts are designed to be self-contained and avoid network calls by default.
- Do not add secrets, `.env` files, private keys, or access tokens to this repository.

HTML Artifacts vs Markdown Output

Use Markdown or JSON as canonical source and HTML as the human-facing view when output gets long, visual, or interactive.

Recommendation

Adopt a hybrid workflow: source in Markdown or JSON, rendered artifact in self-contained HTML.

Why HTML Helps

  • Long reports become easier to scan.
  • Tables, timelines, callouts, and SVG diagrams preserve structure.
  • Throwaway editors let humans manipulate state and export it back.

Risks

Noisy diffs

HTML should not become the only canonical source for durable specifications.

Token cost

Generate HTML only when it materially improves human review.

Portable agent workflow

HTML for humans. Markdown for agents.

An installable Codex and Claude package for turning long reviews, plans, maps, reports, and one-off editors into self-contained HTML artifacts without polluting your source-of-truth context.

Rules Templates Install Prompts Repo

Decision Rules

SituationPreferred FormatReason
Agent memory, project instructions, durable specsMarkdown / JSONReadable diffs, grep, low token cost, easy agent re-use.
Long human-facing reviews or plansHTMLNavigation, visual hierarchy, tables, callouts, timelines.
Architecture maps and PR understandingHTML + SVGSpatial information is easier to scan than prose.
Ticket triage, prompt tuning, feature flagsInteractive HTMLHumans manipulate the state, then export Markdown or JSON.
